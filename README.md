# 15MW Data Center — Project Accounting & Cost Control Case Study

> Simulated portfolio case study using synthetic project, vendor, contract,
> invoice, and financial data. No confidential or employer data is used.

## Project Overview

This project simulates the financial management of a 15MW data center
construction project from the perspective of a Project Accountant.

The case study demonstrates project accounting and cost-control workflows
including:

- Project budget and cost-code management
- Subcontract and purchase-order commitments
- Change-order tracking
- Vendor invoices and subcontractor pay applications
- Retainage
- Actual cost reconciliation
- Estimate to Complete (ETC)
- Estimate at Completion (EAC)
- Budget variance analysis
- Work-in-Progress (WIP) reporting
- Monthly project financial reporting

## Role Simulated

**Project Accountant**

Responsible for maintaining project financial accuracy, reviewing project
costs and commitments, investigating variances with project management,
tracking change orders, supporting forecasting, and preparing monthly
project financial reports.
